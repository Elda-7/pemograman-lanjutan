# Kalkulator

Aplikasi kalkulator sederhana dengan antarmuka GUI menggunakan Tkinter, yang sudah tersedia bersama Python.

## Menjalankan di Windows

1. Instal Python 3 dari [python.org](https://www.python.org/downloads/). Saat instalasi, aktifkan **Add Python to PATH**.
2. Buka Command Prompt atau PowerShell di folder aplikasi.
3. Jalankan:

   ```powershell
   python kalkulator.py
   ```

Kalkulator mendukung penjumlahan, pengurangan, perkalian, pembagian, angka desimal, tombol hapus, serta input melalui keyboard. Tekan **Enter** untuk menghitung, **Backspace** untuk menghapus satu karakter, dan **Esc** untuk mengosongkan.
